# koyeb-tv — منصة قنوات بث 24/7 بأسلوب Viloud (على Koyeb، بدون ffmpeg)

منصة تلفزية مصغرة تعمل بـ **nginx + nginx-vod-module فقط**، مع **لوحة تحكم عربية**:
مكتبة فيديو تُغذّى بروابط مباشرة، قنوات بقوائم تشغيل تتكرر 24/7، قنوات إعادة بث
خارجية (m3u8/TS)، روابط HLS جاهزة لكل قناة، مشغّل ويب، وكود تضمين iframe.

## أولاً: الرفع إلى GitHub ثم Koyeb

ارفع **كل** الملفات التالية إلى المستودع (مثل `mhd56745/sdd`) عبر Upload files:

```
Dockerfile
.dockerignore
nginx/nginx.conf.template
scripts/entrypoint.sh
scripts/admin.py
scripts/build_schedule.py
scripts/gen_locations.py
scripts/mp4_info.py
scripts/media_fetch.py
www/index.html
www/admin.html
www/watch.html
www/embed.html
media/            (اختياري — فارغة أو بملفات MP4)
```

> ملاحظة: احذف الملفات القديمة `scripts/gen_restream.py` و `scripts/restream_env.py`
> إن كانت لا تزال في المستودع — لم تعد مستخدمة.

في Koyeb أنشئ Service من GitHub، Dockerfile build، منفذ **8000**.

## الاستخدام

1. افتح `https://<تطبيقك>.koyeb.app/admin/` وسجّل الدخول.
2. تبويب **مكتبة الفيديو**: أضف فيديو باسمه ورابطه المباشر واختر طريقة التخزين:
   - **تنزيل إلى المحطة**: يُحفظ على القرص (سريع وموثوق) — افتراضي.
   - **عن بُعد**: يُفحص الرابط فوراً بطلبات Range صغيرة ثم يُبث من المصدر مباشرة
     (لا يستهلك قرصاً إطلاقاً — المكتبة بلا حد. MP4/MOV/M4V فقط، ويحتاج مصدراً يدعم Range).
3. تبويب **القنوات**: أنشئ قناة نوع «قائمة تشغيل 24/7» ورتّب فيها فيديوهات
   المكتبة (منزّلة أو عن بُعد، خليطاً أو منفردة)، أو قناة «بث خارجي» برابط m3u8/TS.
4. تنشر كل قناة رابط **m3u8** ثابتاً + صفحة مشغل `/watch/<id>` + كود تضمين
   iframe جاهز للصق في أي موقع.
5. تبويب **الاستوديو**: ارفع شعار القناة (PNG شفاف) وحدّد موضعه وحجمه وشفافيته،
   واكتب نص الشريط الإخباري المتحرك أسفل الشاشة (لون النص والخلفية والسرعة)،
   مع خيار «يُبث الآن» لعرض اسم الفيديو الحالي تلقائياً — كل ذلك يظهر فوق الفيديو
   في صفحات الموقع (الرئيسية/المشاهدة/التضمين) ويُحدَّث دون إعادة تحميل.
   كما يولّد الاستوديو **أمر «الحرق على المصدر»** جاهزاً بإعداداتك (ffmpeg على حاسوبك)
   لمن يريد ظهور الشعار والشريط داخل البث الخام نفسه في VLC وأجهزة IPTV —
   القالب مُختبَر على ffmpeg 7.x مع تشكيل عربي صحيح (libfribidi)،
   وبديل أسهل بدون أوامر: CapCut. قنوات Restream الخارجية تُبثّ كما هي ولا تُعدَّل.

## النسخ الاحتياطي (مهم على Koyeb)

تخزين Koyeb مؤقت يُمسح مع كل نشر جديد. من تبويب **النسخ الاحتياطي** في اللوحة:
صدّر البيانات وضعها في متغير البيئة `SEED_JSON` — عند كل إقلاع تعود القنوات
تلقائياً وتُعاد تنزيل الفيديوهات من روابطها (خلف الكواليس).

التصدير (نسخة v2) يشمل أيضاً **إعدادات الاستوديو وصورة الشعار** (base64) —
فيعود الشعار والشريط النصي تلقائياً مع كل إقلاع. ملاحظة: الشعار يضيف إلى حجم
النص ما يقارب حجم الصورة × 1.4 — إن كان `SEED_JSON` كبيراً جداً لمتغير البيئة،
احذف حقل `logo_b64` من الـ JSON وسيبقى الباقي يعمل.

## الصيغ المدعومة

- **مدعوم**: MP4/MOV/M4V بفيديو H.264 (avc1) وصوت AAC/MP3/AC3 — والبث الخارجي m3u8 أو TS.
- **وضع «عن بُعد»**: MP4/MOV/M4V فقط (تقرأه وحدة vod بطلبات Range)، والمصدر يجب أن يدعم Range.
- **غير مدعوم**: H.265/HEVC، DTS/Opus/TrueHD، MKV بترميزات غريبة، روابط magnet
  (تحتاج عميل تورنت — خارج نطاق المحطة الخفيفة)، وملفات MKV بفيديو H.264 تُقبل
  لكن الأفضل إعادة تغليفها إلى MP4 خارجياً.

## البنية التقنية

- `nginx` (1.28) + `nginx-vod-module` وضع mapped/live: يعيد تغليف MP4 إلى HLS-TS
  مباشرة من الملفات — **بدون ffmpeg نهائياً**. مقاطع الخريطة تحمل `sourceType`:
  `file` (قرص المحطة) أو `http` (قراءة عن بُعد بطلبات Range عبر موقع
  `/vod-remote/` الداخلي).
- `admin.py` (بايثون قياسي فقط، لا مكتبات خارجية): واجهة `/api/`، تنزيل الفيديوهات،
  فحص الروابط عن بُعد (probe_url بطلبات Range بدون تنزيل)، مجدول يولّد خرائط البث
  كل 15 ثانية بخوارزمية حتمية (أرقام تسلسلية متسقة عبر إعادة التشغيل)،
  ثم `gen_locations.py` يولّد مواقع nginx و `nginx -s reload`.
- البيانات: `/data/videos.json` و `/data/channels.json` والخرائط في `/var/vod/maps/live/<id>`.

## الضبط على خطة Koyeb المجانية (0.1 vCPU / 256MB / 2GB)

- الذاكرة: كاشات vod مضبوطة (24m moov + 4m خريطة حية + 4m قوائم ≈ 32MB مشتركة)
  وopen_file_cache 256 وworker_connections 2048 — يبقى الرقيق للمعالجة.
- القرص: حد المكتبة 1500MB + حارس مساحة (رفض تنزيل تحت 300MB حرة) + وضع «عن بُعد»
  الذي يجعل قرص المحطة مستقلاً عن حجم مكتبتك.
- الحمل: وحدة vod تعيد التغليف فقط (لا تحويل ترميز) — استهلاك المعالج منخفض
  لكل مشاهد، والمقاطع الناتجة أسماؤها ثابتة مع صلاحية ساعة — مثالية للكاش.

### مضاعفة القوة مجاناً: Cloudflare أمام المحطة

مقاطع TS الناتجة أسماؤها ثابتة لكل المشاهدين (الخوارزمية حتمية) وصلاحيتها ساعة —
ضع نطاقك خلف Cloudflare (خطة مجانية) وأضف قاعدة كاش:

1. نطاقك في Cloudflare → DNS → سجل يشير إلى نطاق Koyeb مع تفعيل Proxied (سحابة برتقالية).
2. Rules → Cache Rules → قاعدة جديدة: تطابق Host = نطاقك و URI Path يبدأ بـ
   `/live/` وتنتهي بـ `.ts` → Eligible for cache + Cache everything + Respect origin TTL.
3. النتيجة: المقاطع تُخدَم من شبكة Cloudflare العالمية، والمحطة تستقبل طلباً واحداً
   لكل مقطع — جمهور أكبر بكثير على نفس العتاد، وحصة نقل أقل على Koyeb،
   مع TLS وحماية DDoS مجاناً.

ملاحظات صادقة: ملفات m3u8 لا تُخزَّن (تتغير باستمرار — طبيعة البث الحي)،
والمقاطع الخارجية (`/restream/`) تبقى دون كاش لأنها أصول الغير. وحدود العتاد
المادي تبقى: لا تحويل ترميز (المحطة تعيد التغليف فقط)، وجمهور مئات المشاهدين
المتوازيين يتطلب خطة Koyeb أعلى.
